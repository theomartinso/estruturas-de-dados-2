# Estruturas de Dados (AED2)

Implementações de estruturas de dados desenvolvidas na disciplina de Algoritmos e Estruturas de Dados 2, na Engenharia da Computação (UFAM).

## Conteúdo

- **Árvore binária de busca** (`arvore-binaria/`): inserção, busca, remoção e percurso em ordem

## Como compilar e executar

```bash
cd arvore-binaria
gcc arvore_binaria.c -o arvore_binaria
./arvore_binaria
```

## Tecnologias

- C
- Compilador gcc
